EKdelta Desktop — macOS 安裝方式
=============================

推薦：圖形化 .pkg 安裝器
-----------------------
1. 雙擊「EKdelta Desktop-….pkg」。
2. 跟著 macOS 的「安裝程式」按「繼續」完成安裝。
3. 到「應用程式」打開 EKdelta Desktop。
4. 第一次開啟會出現初始設定；只有需要編譯 REVTeX / LaTeX PDF 時才需要安裝 Engine Pack。

備用：.command 基礎安裝器
-----------------------
如果收到的資料夾內有「EKdelta Desktop.app」與「安裝 EKdelta Desktop.command」：
1. 雙擊「安裝 EKdelta Desktop.command」。
2. macOS 會詢問管理員密碼，把 App 安裝到「應用程式」。
3. 完成後會自動打開 EKdelta Desktop。

一般使用者不需要 npm、Node.js、Electron，也不需要在終端機輸入指令。
