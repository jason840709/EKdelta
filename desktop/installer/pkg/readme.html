安裝後會發生什麼？

  • App 會安裝到 /Applications/EKdelta Desktop.app。
  • 第一次開啟會出現「初始設定」導引。
  • 一般 Markdown、表格、圖片與 MathLive 公式不需要額外安裝。
  • 只有要編譯 REVTeX／LaTeX PDF 時，才需要另外選擇 Engine Pack。程式會用圖形化對話框引導你完成。
  • 日後更新 HTML 版本不必重新安裝 App：在「桌面殼 → HTML 版本 → 匯入新版 HTML…」即可。

注意：目前內部測試版可能尚未經 Apple 公證。若 macOS 阻擋第一次開啟，請到「系統設定 → 隱私權與安全性」依系統提示允許開啟；正式對外散布時應使用 Apple Developer 簽章與公證。
