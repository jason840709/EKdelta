Ekdeta 1.2.3 — Windows x64 使用方式
====================================

最簡單：執行「製作 Windows x64 免安裝版_免Node.cmd」，完成後解壓 portable ZIP，直接開 Ekdeta.exe。
如果希望固定安裝，雙擊 portable 資料夾內的「安裝 Portable 到本機.cmd」。

一般 Markdown、MathLive 與臺灣論文不需要 LaTeX Engine Pack。
只有 REVTeX 真實 PDF 編譯需要；請依 repository 的 docs/REVTeX-ENGINE.md 下載並安裝五個 BusyTeX / TeX Live 2026 recommended 檔案。

本公開版未附商業 code-signing 憑證；第一次啟動可能出現 Windows SmartScreen 提示。請只執行你從可信 GitHub Release 取得且 SHA-256 已核對的檔案。
