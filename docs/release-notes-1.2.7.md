# EKdelta 1.2.7

EKdelta（1.2.2–1.2.3 名為 Ekdeta）是一個單一 HTML 的 Markdown 研究寫作環境，支援臺灣學位論文與 REVTeX 4.2 國際期刊稿件。1.2.6 沒有另外發布，它的改動也包含在這一版。

## 這一版（1.2.7）

- 整個介面改用同一套顏色、字級、圓角與動畫：顏色降低飽和度，選單、提示與對話框用同一種底色和陰影，拿掉毛玻璃；切換分頁、選取檔案時，底色平順滑到新位置。
- 「羊皮紙」主題換成「苔灰」，比較不刺眼；原本用羊皮紙的設定會自動換成苔灰。
- 側欄、工具列、狀態列與國際論文右半邊之間的分隔線改清楚，一眼看得出分區。
- 偏好設定重新設計：分成一般、圖片、字體、論文四類，只留設定一次就不常動的項目，外觀和主畫面一致。焦點模式、打字機模式、頁面縮放與顯示工具列在「顯示」選單。
- 國際期刊的期刊、欄數、紙張等，在國際論文左半邊右上角的「版面設定」調整：最上面只放五個常用項目，其餘收在「更多設定」。
- 工具列與標題列的圖示重畫成同一套，大小、線寬與位置一致；刪除線、行內程式碼與字級按鈕更好認。
- 所有可以捲動的地方都看得到捲軸；國際論文左右分割時，中間不再有一條白線。
- 視窗窄於 700 像素（手機或分割畫面）時，左側檔案欄自動收起，按側欄按鈕從左邊滑出。
- 國際論文：直接貼上的圖片會印在 PDF 上，也會放進匯出的 .zip；GIF、WebP、SVG 會先轉成 PNG。
- 拿掉時鐘與裝飾用的紅黃綠視窗鈕；「寬版頁面」移到「顯示」選單。「自訂工具列」與「匯出 REVTeX 專案」的視窗改得更簡單。
- 清掉沒有入口的舊程式與「TeX 精確校樣」舊視窗；編譯前不再多做一次一定失敗的連線，瀏覽器不會因此詢問是否允許存取本機裝置。
- Mac 桌面版改名 EKdelta、換上新圖示，原本的文件與設定照常沿用。

## 一起帶上的 1.2.6

- revtex-／twthesis- 開頭的論文資料區塊（作者與單位、摘要、版面設定、封面等）在編輯畫面自動換行，不再一行到底、需要左右拉捲軸；區塊名稱不再蓋住第一行。一般程式碼區塊維持不換行。
- 國際論文 PDF 中，$333$ 這類只有數字的行內公式正確排成公式（原本被當成金額照原文印出）；「$5 and $10」這類金額寫法仍照原文。
- 格式工具列兩排還放不下時，收起的工具放在第二排末尾的小「⋯」：滑鼠移過去就彈出小框，用原本的圖示排列，滑過圖示一樣顯示名稱；拖動視窗寬度時，格式列不再在兩排與三排之間閃爍。
- 國際論文：右側預覽、「下載 .tex」、主選單「匯出 LaTeX」、REVTeX 專案 .zip、TeX 校樣與 PDF 匯出改由同一個轉換產生，不會再拿到彼此不同的 main.tex；「下載 .tex」給的是目前的內容。設定面板的「使用 CP171 發射器」開關因此移除。
- 國際論文：標題、摘要、關鍵字、致謝、圖表說明、表格、腳註與書目裡的數學、粗斜體和引用都正確轉換；p < 0.05、a | b、直引號、直接打的希臘字母與 ≤ 等符號正確印出，emoji 等無法排版的字元會拿掉並提醒；行內程式碼放在粗體、標題、表格或腳註裡不再讓整份編譯失敗。
- 單字中間的底線（snake_case、file_name）不再變成斜體，左邊畫面與 PDF 一致；「$5,$10」這類金額在左邊畫面也照原文顯示；\(…\)、句中的 $$…$$ 與 ```math 區塊都排成公式。
- 國際論文的參考文獻依正文第一次引用的順序編號（APS 慣例）；[@key, p. 3] 印出頁碼；有腳註又用手寫書目時，腳註不再印成 [?]；PRL 這類不編章節號的期刊，章節引用改印章節標題。
- 國際論文公式：在收尾的 $$ 後面寫 {-} 就是不編號的公式；{#eq:名稱} 寫在收尾 $$ 前後都可以，align、multline 等環境也會加上標籤；split 不再編譯失敗。revtex-wide 區塊裡的表格變成有編號、可引用的跨欄表。
- 匯出的 .tex 與 .zip 是 APS 投稿版：不含 APS 作者指南不允許的 \sbox、\IfFileExists、\resizebox 等寫法，寬公式與寬表格依右側最近一次編譯量到的結果直接寫出折行或跨欄。

## 下載

- `EKdelta-1.2.7.html`：用 Chrome 或 Edge 直接開啟的完整單檔 App。
- `EKdelta-1.2.7-source.zip`：這個 repository 的完整內容（Core source、Desktop source、文件與測試）。
- `EKdelta-Electron-Desktop-1.2.7.zip`：獨立 Electron 建置包，macOS / Windows 可各自產生安裝版，App 名稱 EKdelta、附新圖示。
- `SHA256SUMS.txt`：以上檔案的 SHA-256。

REVTeX 編譯需要另外下載 BusyTeX 1.2.3 / TeX Live 2026 recommended 引擎（見 `docs/REVTeX-ENGINE.zh-TW.md`）。舊版的文件與設定可直接沿用。
