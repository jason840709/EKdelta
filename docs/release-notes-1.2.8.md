# EKdelta 1.2.8

EKdelta 是一個單一 HTML 的 Markdown 研究寫作環境，支援臺灣學位論文與 REVTeX 4.2 國際期刊稿件。上一個公開版本是 1.2.5，所以 1.2.7 的改動也一起列在下方。

## 這一版（1.2.8）

- 字體顏色的調色盤照 Word 的排法重做：一列基本色，下面同色由淡到深相連成色帶；色塊不再印看不到的色碼，滑過才顯示名稱與色碼。新增「移除文字顏色」；「其他顏色」改在同一個浮層裡切換。
- 字色按鈕的 A 放大、和下方色條靠近，色條保留圓角。
- 格式列右側的 REV、TW 論文工具重做：左邊依寫論文的順序分類，右邊是表單。文件裡已有的標題與作者、摘要、致謝、參考文獻、封面、審定書、關鍵字會先讀進表單，按「更新」直接改原本那一份，不會再多插一份；目錄、附錄已存在時改成「跳到該處」。
- 引用可以直接勾選文件裡的參考文獻；交叉引用可以挑文件裡設過標籤的圖、表、公式與章節。參考文獻用名稱（而不是編號）標示時，引用也會用名稱。
- 修正：臺灣論文的圖說改成排版認得的「圖 2.1：」寫法，會進圖目錄；插圖的圖說換行不再讓圖消失；在表單裡打字後，內容插回原本的游標位置，不會跑到文件最後。
- 國際論文模式只顯示 REV，臺灣論文模式只顯示 TW。
- 國際論文左半邊的「版面設定」改成和偏好設定同一套外觀：上面是投稿目標與常用項目，其餘收在「更多設定」；說明泡泡的內容和選項對齊。
- 偏好設定分成一般、圖片、字體、臺灣論文、國際論文五類。國際論文頁可以指定新論文的預設期刊、排版模式與紙張，並直接打開這份文件的版面設定；臺灣論文頁可以切換電子版或紙本雙面。匯出 LaTeX 時「表格用三線表」「程式碼標註語言」兩個選項，從「檔案」選單移到偏好設定「一般」。
- 其他視窗統一外觀：關閉檔案、圖片讀不到原檔、PDF 診斷、分批匯出 PDF、表格格線、快速開啟與公式輸入的符號鍵；「檔案」選單的匯出項目依格式分組；介面中文的標點改成全形。
- 桌面版改名「EKdelta Desktop」，Dock 會顯示新圖示（安裝時把舊名稱的 App 移到垃圾桶；Dock 上的舊釘選要重新釘一次）。

## 一起帶上的 1.2.7

- 整個介面改用同一套顏色、字級、圓角與動畫：顏色降低飽和度，選單、提示與對話框用同一種底色和陰影，拿掉毛玻璃；切換分頁、選取檔案時，底色平順滑到新位置。
- 「羊皮紙」主題換成「苔灰」，比較不刺眼；原本用羊皮紙的設定會自動換成苔灰。
- 側欄、工具列、狀態列與國際論文右半邊之間的分隔線改清楚，一眼看得出分區。
- 偏好設定重新設計：分成一般、圖片、字體、論文四類，只留設定一次就不常動的項目，外觀和主畫面一致。焦點模式、打字機模式、頁面縮放與顯示工具列在「顯示」選單。
- 國際期刊的期刊、欄數、紙張等，在國際論文左半邊右上角的「版面設定」調整：最上面只放五個常用項目，其餘收在「更多設定」。
- 工具列與標題列的圖示重畫成同一套，大小、線寬與位置一致；刪除線、行內程式碼與字級按鈕更好認。
- 所有可以捲動的地方都看得到捲軸；國際論文左右分割時，中間不再有一條白線。
- 視窗窄於 700 像素（手機或分割畫面）時，左側檔案欄自動收起，按側欄按鈕從左邊滑出。
- 國際論文：直接貼上的圖片會印在 PDF 上，也會放進匯出的 .zip；GIF、WebP、SVG 會先轉成 PNG。
- 拿掉時鐘與裝飾用的紅黃綠視窗鈕；「寬版頁面」移到「顯示」選單。「自訂工具列」與「匯出 REVTeX 專案」的視窗改得更簡單。
- 清掉沒有入口的舊程式與「TeX 精確校樣」舊視窗；編譯前不再多做一次一定失敗的連線，瀏覽器不會因此詢問是否允許存取本機裝置。
- Mac 桌面版改名 EKdelta、換上新圖示，原本的文件與設定照常沿用。

## 下載

- `EKdelta-1.2.8.html`：用 Chrome 或 Edge 直接開啟的完整單檔 App。
- `EKdelta-1.2.8-source.zip`：這個 repository 的完整內容（Core source、Desktop source、文件與測試）。
- `EKdelta-Electron-Desktop-1.2.8.zip`：獨立 Electron 建置包，macOS / Windows 可各自產生安裝版，App 名稱 EKdelta Desktop。
- `SHA256SUMS.txt`：以上檔案的 SHA-256。

REVTeX 編譯需要另外下載 BusyTeX 1.2.3 / TeX Live 2026 recommended 引擎（見 `docs/REVTeX-ENGINE.zh-TW.md`）。舊版的文件與設定可直接沿用。
