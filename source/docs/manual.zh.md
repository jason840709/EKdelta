# 使用說明

> 本手冊對應 **Ekdeta 1.2.3（2026.09）**。

## 這份手冊怎麼讀

手冊分成三部分，可以只讀你用得到的：

- **第一部 基礎操作（第 1–10 節）**：不管你寫什麼都會用到——存檔、介面、編輯、表格、圖片、匯出。
- **第二部 三種寫作模式（第 11–14 節）**：先介紹一般 Markdown，再集中說明 A4 與 PDF 匯出，接著介紹 臺灣碩博士論文與國際期刊 REVTeX。可依目前模式查閱對應章節。
- **第三部 設定與參考（第 15–20 節）**：偏好設定、主題字體、故障排除、快捷鍵、已知限制。
- **附錄 A** 是完整選單總覽，當作查表用。

新手請先讀左側的「歡迎使用」，那裡有四步驟入門。

# 第一部 · 基礎操作

## 1. 資料放在哪裡：儲存與備份

Ekdeta 可直接在瀏覽器開啟，也可搭配桌面殼使用。程式不會自動上傳文件。分隔線下方的一般文件與設定儲存在瀏覽器裡；輸入停止後約 1.2 秒自動寫入。最上方六份內建文件由目前版本提供，修改不會永久保存。

儲存、備份、資料夾同步與 `.md` 匯出會保留未修改的原始文字，包括換行格式、YAML、HTML 註解、數學圍欄與其他擴充語法。

**瀏覽器儲存不是長期備份。** 請至少選一種：

- **Chrome／Edge**：「檔案 → 連結儲存資料夾…」。每份一般文件會同步成 `.md`，同一資料夾另有 `ekdeta-data.json` 保存文件、目前選取與設定。內建文件不重複寫入。瀏覽器重啟後可能再次要求資料夾權限，請重新授權後繼續同步。
- **任何瀏覽器**：定期「匯出完整備份 (.json)」；換電腦時用「還原備份…」。
- **重要成品**：另外匯出 `.md`、單一 HTML 或 PDF。

四個備份指令的實際操作：

1. **連結儲存資料夾**：選單顯示「已連結：資料夾名稱」後即開始同步。「中斷資料夾連結」只停止同步，不刪任何檔案。
2. **匯出完整備份 (.json)**：下載一個 JSON，內含全部一般文件、目前選取與設定。
3. **還原備份…**：以備份內容**取代**目前的一般文件與設定，完成後顯示還原的文件數。
4. **從資料夾載入…**：讀取已連結資料夾裡的 `ekdeta-data.json`，用於在另一台電腦接續同一份工作。

「恢復原廠設定」會清除瀏覽器內的一般文件與設定，並重新載入目前版本的六份內建文件；已寫到外部資料夾的 `.md` 不受影響。

## 2. 介面與側邊欄

- 選單列：Ekdeta、檔案、編輯、段落、格式、顯示、主題、模式、說明。桌面殼另外提供桌面殼與視窗選單。
- 標題列顯示目前文件；右上角提供顯示控制。「主題」改外觀，「模式」選文件排版，兩者可分開設定。
- **格式工具列**在側邊欄右側、文件內容頂端。預設開啟，最左固定復原／重做，其餘依自訂順序排列，真的塞不下才收進「⋯」。
- 左側三個頁籤：
  - **檔案**：最上方六份內建文件（歡迎使用、使用說明、開發筆記、臺灣論文模板（中文）、臺灣論文模板（英文）、國際期刊論文模板），分隔線以下是一般文件。可新增、切換、重新命名、關閉，也可拖入 `.md`。**⌘P 快速開檔**依檔名模糊排序。
  - **大綱**：可輸入文字篩選標題、摺疊或展開章節，並標示目前所在位置。重複標題依實際順序精準定位。臺灣論文各版型會同步顯示章、節、小節與附錄編號。
  - **搜尋**：跨全部文件搜尋，結果顯示檔名、行號與前後文，點擊即可跳轉。
- 右上角四組按鈕：側邊欄（⇧⌘L）、原始碼模式（⌘/）、明暗切換、字級縮小／放大／還原。
- 底部狀態列顯示字數、閱讀倍率、版本與儲存狀態；選取文字時另外顯示選取範圍。

**內建文件與一般文件的分界**：六份內建文件可暫時編輯，但切換離開、重新整理或重開後會恢復原文。要保存修改，請先從模板建立一般文件，或把需要的內容複製到新增文件。同名的一般文件仍可正常儲存、改名與關閉。

**原始碼模式**：按 ⌘/ 進入（Windows／Linux：Ctrl+/），再按一次回到排版。游標仍在畫面內時會對應到該位置；已捲離游標時，則以目前可見內容為準。此模式提供語法著色、行號、目前行提示與大綱導覽，可直接編輯完整 Markdown；復原／重做針對原始碼中的編輯。等寬字體可在偏好設定調整。

## 3. 建立、儲存與管理文件

- **新增與切換**：「＋ 新增檔案」或「檔案 → 新增檔案」；⌘N 在多數瀏覽器會被攔截成開新視窗，被攔截時請用選單。切換文件在「檔案」頁點一下，或用 ⌘P。
- **儲存**：一般文件輸入停止約 1.2 秒後自動寫入；⌘S 立即儲存並提示「已儲存至瀏覽器」或「已儲存(瀏覽器 + 資料夾)」。內建文件不參與儲存。
- **重新命名**：對一般文件連點兩下，或「檔案 → 重新命名…」。
- **開啟與匯入**：「檔案 → 開啟 Markdown…」接受 `.md`、`.markdown`、`.txt`，也可直接把檔案拖進視窗。匯入後的文件與磁碟原始檔**沒有連動**，後續修改保存在程式裡。拖入圖片檔會插入圖片而不是開新文件。
- **關閉**：「檔案 → 關閉此檔案」。已連結資料夾時直接關閉並保留資料夾中的 `.md`；未連結時會跳出「儲存（.md）並關閉／不儲存，直接關閉／取消」三選一，因為此時關閉會把檔案從瀏覽器儲存中移除。

## 4. 編輯方式與 Markdown

游標進入單一段落時，該段落顯示原始 Markdown；離開後重新渲染。粗體、斜體、連結、行內碼與公式可逐段點擊，不必展開整個段落。臺灣論文的 A4 分頁畫面為了維持分頁改用浮動編輯框，頁面本身保持渲染狀態，且可直接點擊頁面文字移動插入點。

支援的常用區塊：

- H1 至 H6 標題、一般段落、引言、水平線。
- 無序、有序與任務清單；Tab／Shift+Tab 或 ⌘]／⌘[ 調整層級。清單項目可以直接包含標題，例如 `1. #### 章節`。
- 程式碼圍欄、數學區塊、Markdown 表格。
- 行內粗體、斜體、底線、刪除線、螢光標記、程式碼、公式、連結、圖片。
- 行首輸入 `# `、`- `、`1. `、`> `、`- [ ] ` 可快速轉換；輸入三個反引號或 `$$` 後按 Enter 會展開區塊。

清單與引言在套用後**立即保持渲染**：圓點、編號、核取框或引用框不會先退回原始 marker。非空內容按 Enter 建立下一個同類型項目，空項目再按一次 Enter 才退出；內容開頭按 Backspace 可取消該結構。

**工具列與快捷鍵使用相同的格式操作。** 可在一般文字、行內編輯、表格儲存格、原始碼模式與浮動編輯框中使用。點工具列會保留選取範圍，因此可連續套用格式。

- 選取範圍內只有部分粗體／斜體時，程式會先移除內層同類標記，再讓整段得到單一一致語意；整段原本都已套用時，再按一次才取消。
- 引用 `[[1]]`、行內公式、圖片與行內程式碼會作為完整內容處理，格式操作不會拆開其語法。
- 「清除格式」只清除行內格式與連結外框，保留連結文字，並拒絕破壞程式碼圍欄、區塊公式或整張表格。

**首行縮排**：把游標放在段落上按 **⌥⌘0** 可切換該段的首行縮排。一般段落把標記存在行首，引言存在 `> ` 之後以維持標準 Markdown 語法；渲染畫面與 PDF 不顯示這個標記。

智慧配對支援括號、引號、反引號與 `* _ ~ = $`；選取文字後輸入配對符會包住選取範圍。中文輸入法組字、程式碼、表格與數學區塊中會避開不適合的自動配對。

## 5. 智慧貼上與自動補全

一般貼上會先檢查剪貼簿內容：

- 網頁或 Word 的 HTML 轉成 Markdown，保留可對應的粗體、斜體、行內碼、刪除線、連結與圖片。
- TSV／CSV 或單一 HTML 表格轉成 Markdown 表格，儲存格內的行內格式會保留。
- 剪貼簿圖片依偏好設定寫入圖片資料夾，無可寫入位置時改為 base64 內嵌。
- 不希望轉換時用 **⇧⌘V 貼上為純文字**。

自動補全出現在四個位置：數學中輸入 `\` 加指令開頭（KaTeX 指令）、程式碼圍欄第一行（語言名稱）、一般文字輸入 `:名稱`（emoji）、連結目標輸入 `](#`（文件內標題錨點）。候選支援模糊搜尋、方向鍵、Page Up／Down、Home／End，並記住最近使用項目；Enter 只在選中候選時套用，Esc 關閉。

## 6. 尋找、取代與導覽

- **⌘F** 尋找目前文件；**⌥⌘F** 開啟取代列。
- 尋找列的 **Aa／W／.*** 分別控制大小寫、整字比對與正規表達式，選項會記憶。
- 所有命中會在文件中高亮；Enter／⇧Enter 或 ⌘G／⇧⌘G 前後移動。「全部取代」可用一次 ⌘Z 還原。
- **⇧⌘F** 搜尋所有文件；**⌘P** 快速開檔。
- 大綱標題與 Markdown 內部錨點使用近似 GitHub 的 slug 規則，重複標題會自動加序號；⌘+點擊內部連結可跳到對應標題。
- 原始碼模式下請使用瀏覽器內建搜尋。

## 7. 表格

- ⌥⌘T 或「段落 → 表格」可用格線選擇列數與欄數。
- 點入表格後逐格編輯：Tab／Shift+Tab、Enter、方向鍵移動；最後一格按 Tab 新增一列；Esc 完成。空白儲存格保有一行高度，不會被壓扁。
- 工具列可插入或刪除行列、設定對齊。拖曳欄界可調整欄寬，欄寬換算成百分比跟著文件保存，切換主題或重開後仍可重建。
- **單頁**是快速切換；**版面…**可設定分頁方式（自動／整表同頁／填滿單頁）、表格寬度、字體比例、行距與儲存格間距，也可套用標準、緊湊、極緊湊或填滿單頁預設。這些屬性以緊貼表格的隱藏註解保存，其他 Markdown 編輯器會忽略它。
- 普通 Markdown 模式沒有紙張高度，因此「填滿單頁」只呈現穩定的緊湊預覽，不會插入 A4 空白。切到 A4 模式後才依當下版心實測：先調寬度、外距、內距與行距，最後才縮小字體。
- 「整表同頁」不主動壓縮，只在表格能放進一個完整頁面時整張移頁；「填滿單頁」會在安全範圍內自動適配。若已降到最低設定仍高於一頁，系統會回退成逐列跨頁與續頁重複表頭，避免裁掉資料。
- 儲存格內的直線字元 `|` 會在寫回 Markdown 時自動跳脫。

## 8. 數學、程式碼、註腳、HTML 與錨點

- **數學**：內嵌 KaTeX，支援行內 `$…$`、區塊 `$$…$$`、`\[…\]` 與 math 圍欄。點擊公式可逐式編輯，浮動框即時預覽；錯誤公式會顯示原始碼與錯誤提示，不會讓整份文件停止渲染。
- **公式編號**：在區塊公式內加入 `\tag{2.19}` 可指定編號；一般畫面與 PDF 匯出會保留公式和編號的分隔。分批匯出不會把公式從 1 重新編號。過寬公式仍建議分行，並檢查輸出結果。
- **程式碼**：圍欄支援 JavaScript、TypeScript、Python、C/C++/C#、Java、Kotlin、Go、Rust、Swift、PHP、SQL、Shell、HTML、CSS、JSON、YAML、LaTeX 等語言與別名；未知語言以純文字顯示。
- **註腳**：寫 `這是一個註腳引用[^method]。` 與 `[^method]: 註腳內容。`，引用與定義可互相跳轉。id 可用英數、`.`、`_`、`-` 與中文，目前依 id 顯示、不自動重編號。
- **行內 HTML**：`<u>`、`<kbd>`、`<mark>`、`<sup>`、`<sub>`、`<details>` 等白名單標籤會渲染；`<script>`、事件屬性、`javascript:` URL 與 iframe 會被移除或拒絕。複雜多行版面建議改用 Markdown。
- **錨點**：`[文字](#標題)` 可跳到文件內的標題。

## 9. 圖片

- 可貼上截圖、拖入圖片檔、插入網路網址，或直接寫 `![alt](path)`／`<img src="…">`。
- 偏好設定可選：儲存資料夾的子資料夾（預設 `image/`）、獨立圖片資料夾、或全部 base64 內嵌。
- 點擊圖片會出現縮放工具，可選 25／33／50／66／100%、輸入自訂百分比、編輯路徑與 alt，或切換 Markdown／HTML 圖片語法。
- 本機圖片失效時底部會顯示修復列，「查看缺圖清單」可看到完整路徑、所在頁面與重複引用次數；選一次圖片資料夾即可依相對路徑與尾碼重新配對。

## 10. 複製、匯入與匯出

「編輯」選單可複製為 **Markdown**（保留原始語法）、**LaTeX**（標題、清單、表格、公式、註腳與圖片轉成對應語法）或 **HTML（Word 可貼）**。有選取範圍時只處理選取內容，否則使用正在編輯的區塊、游標區塊或全文。

「檔案」選單可匯出：Markdown `.md`、通用 LaTeX `.tex`（可選 booktabs 表格與 listings 程式碼）、一般 HTML、單一 HTML（圖片內嵌）、PDF（向量／可搜尋）、分批 PDF、相容點陣 PDF、完整備份 `.json`。PDF 的差異與操作見第 12 節。REVTeX 文件請從右側面板下載編譯後的 `.tex`，或從「檔案」匯出 REVTeX 專案 `.zip`（見第 14 節）。

HTML 與 Markdown 匯出不等同完整備份；要搬移全部文件與設定請用完整備份。

# 第二部 · 三種寫作模式

## 11. 一般 Markdown

預設模式，適合筆記、文章與草稿。主題可選 GitHub、Night、羊皮紙、Blackout、Blackout Game。沒有紙張與分頁概念，字級每次調整 1 px，內容寬度隨視窗；縮放與側邊欄切換後會自動回到水平中央。

## 12. A4 分頁與 PDF 匯出

臺灣論文中英文模式會在編輯畫面顯示 A4 紙張、分頁與頁碼。段落、圖片、程式碼與表格依頁面可用高度推移或拆分；超高圖片等比縮放。字級每次調整 0.5 pt，紙張與頁邊距不隨字級改變，但內容會重新分頁。

「偏好設定 → 論文輸出設定 → 填滿每一頁」預設開啟，允許文字、引言、程式碼等在頁界續排；行內公式跟著整行文字換頁。關閉後，可在完整頁面放下的段落會整段移到次頁。

### 12.1 選擇輸出方式

| 輸出方式 | 適合情況 | 儲存方式 |
| --- | --- | --- |
| 匯出 PDF（向量／可搜尋） | 一般文件；需要可搜尋、可選取的文字 | 系統列印 → 另存為 PDF |
| 分批匯出 PDF（大檔案建議選用） | 長文件；分次處理可降低每次列印負擔 | 每批另存一份 PDF，再自行合併 |
| 相容點陣 PDF（直接下載） | 需要以圖片方式輸出的相容備援 | 直接下載；文字不可搜尋，放大會像素化 |

一般與分批 PDF 都保留文件原本的公式編號。匯出前先處理缺圖提示，確認圖片已在文件中載入。大檔案首次載入與分頁仍需要時間；分批匯出限制的是每次交給列印的頁數。

### 12.2 一般向量 PDF

1. 選「檔案 → 匯出 PDF（向量／可搜尋）」。
2. 準備完成後，在系統列印視窗選「另存為 PDF」或同等目的地。
3. 使用 A4、縮放 100%；若有頁首頁尾選項，請關閉瀏覽器加上的頁首頁尾。
4. 儲存後開啟 PDF，確認分頁、圖片與公式顯示符合預期。

文字可搜尋、可選取，目錄連結可在支援的 PDF 閱讀器中使用。若準備程序顯示問題，先依訊息修正後再匯出。

### 12.3 分批匯出 PDF（大檔案建議選用）

在「檔案」選單選擇此項，可選每批 100、50、25 或 10 頁，預設 50 頁。頁次從整份文件第一頁（含封面）計算；內文原頁碼與公式編號保留。

1. 選擇每批頁數與頁面範圍，按「準備本批頁面」。
2. 就緒後按「開啟列印畫面」，在系統列印中選「另存為 PDF」與「全部」頁面。此時列印文件只有本批，預設檔名會自動帶入頁數範圍，例如 `文件名稱_第 51 到 100 頁.pdf`。
3. 等列印與存檔視窗都已關閉，回到軟體並確認檔案已儲存，再按「本批已儲存，選下一批」。軟體會先清理本批列印內容，清理完成後才開放選擇、準備下一批。如果取消列印，按「未儲存／重印本批」，同樣會先清理上一份列印內容再重新準備。
4. 按「準備本批頁面」手動繼續，直到所有批次完成。若沒有自動返回，先關閉系統列印與存檔視窗，再按「列印視窗已關閉，返回批次」，等待清理完成後確認本批是否已儲存。

軟體偵測到列印流程返回時，無法判斷你按了儲存還是取消，也不會立即清除仍可能供存檔視窗使用的列印內容；請在視窗確實關閉後再確認。清理期間請等待操作重新開放。

批次選單關閉前暫停編輯，保持整份文件的頁面一致；本次完成狀態不跨軟體重啟保存。每批是獨立 PDF，不自動合併。跨批目錄連結保留文字而停用跳轉；同批連結保留。原有一般向量 PDF、相容點陣 PDF 與系統列印仍可使用；REVTeX 請沿用原有 TeX PDF 匯出。這個功能限制每次新增的列印內容；首次全文載入及分頁仍需要時間與記憶體。

### 12.4 相容點陣 PDF 與系統列印

「相容點陣 PDF（直接下載）」把每頁輸出為圖片，目錄頁碼仍可附帶內部跳頁連結。它會一次處理整份文件；長文件優先考慮分批匯出。

「列印（系統對話框）」保留一般列印入口。REVTeX 文件請使用右側面板的「下載 PDF」，操作見第 14 節。

## 13. 臺灣論文（中文／英文）

這兩個模式用於臺灣碩博士論文的中文與英文排版。中文版提供 classicthesis 風格內文與國立中山大學範例封面；英文版提供英文封面、版權頁、斜體小節標題與英文系統標籤。校名、系所、人員與日期皆可自行修改；交稿前請依所屬學校與系所的最新規範確認版型。請先照「歡迎使用」第 4 步從模板建立一般文件再開始寫。

- **中文版電子版 1**：對稱精簡版心、中央頁碼、無頁首、無空白插頁。
- **中文版電子版 2**：對稱書冊版心、中央頁碼、章／節頁首。
- **English Digital**：對稱版面、中央頁碼、無頁首。
- **中文版與 English Print**：雙面鏡像書冊，裝訂內緣 33.58 mm、書口外緣 25.29 mm，頁碼在書口外側，章節依 openright 規則在必要時插入空白頁。English Print 章首頁無頁首，其餘偶數左頁顯示章名、奇數右頁顯示現行節名與通欄細線。

模板語法：`twthesis-titlepage` 產生封面（欄位含中英文系所、論文類型、標題、研究生、指導教授與日期；輸出使用正式標籤，不會顯示表單欄位名稱）、`twthesis-approval` 放置完整 A4 審定書圖（圖片路徑、口試日期）、英文模式另有 `twthesis-titleback` 版權頁、`twthesis-toc`／`twthesis-lof`／`twthesis-lot` 產生目錄與圖表目錄、`twthesis-appendix` 之後的章自動改用附錄編號、`[[N]]` 為引用記號。摘要關鍵字維持單行 Markdown 寫法（粗體 `關鍵字：`／`Keywords:` 開頭），顯示時自動排成兩行齊左並置於版心底部。

這些圍欄語法都可以透過格式工具列右側的 **論文** 分類鈕填表單產生，不用手打；封面表單會依目前的臺灣論文中文或英文模式自動預選對應欄位。

首行縮排在「偏好設定 → 論文輸出設定 → 縮排設定」：中文版可選首行兩字（預設）或全部不縮排；English 可選全部不縮排（預設）、每段首行 0.5 in，或標題後首段齊左、其餘 0.5 in。圖說、參考文獻、關鍵字與明示 `<!-- noindent -->` 仍維持零縮排。

## 14. 國際期刊 REVTeX 4.2

這個模式和前面兩種**運作方式完全不同**：不是用 HTML 模擬 LaTeX 的排版，而是**左邊寫 Markdown、右邊顯示由真正的 pdfLaTeX（REVTeX 4.2）編譯出來的 PDF**。右邊看到的就是你投稿時要交的那一份。

### 14.1 進入與初次設定

1. 選「模式 → 國際期刊 REVTeX 4.2」。左側維持一般 Markdown 編輯，右側開啟 PDF 面板。
2. 右側面板會請你**載入編譯引擎（Engine Pack）**。這是一次性動作，載入後就能邊寫邊編譯。
3. 按左側「版面設定」選學會與期刊（APS 的 PRL／PRA／PRB／RMP 等、AIP 的 JCP／APL／JAP 等、AAPM 的 MPH、SOR 的 JOR）、稿件模式（reprint／preprint／manuscript）、欄數、紙張、字級、單位排列、引用格式與 class option。選項依官方 `revtex4-2` 提供，並隨目前文件保存。
4. 字級建議保留「依排版模式自動」。這不是畫面縮放：REVTeX 官方 `preprint`／`manuscript` 使用 12 pt，`reprint` 使用 10 pt。切換稿件模式時，該文件的字級會回到自動，避免把 preprint 的 12 pt 帶進 reprint。舊版文件若保存了 AIP、reprint、Letter、雙欄與 11 pt／12 pt 的組合，開啟時也會改回自動；正文內容不變。

### 14.2 稿件語法

在 Markdown 裡用圍欄標示 REVTeX 的語意區塊：

- `revtex-frontmatter`：標題、作者、單位、email、通訊作者、preprint 編號、PACS、關鍵字。單位可先列成有序清單（`affiliations:`），作者再用 `affil: 1,3` 這種索引指過去，不必把長長的單位名稱重複貼十幾次。
- `revtex-abstract`：摘要（可多段）。
- `revtex-acknowledgments`：致謝。
- `revtex-wide`：需要跨欄的內容。
- `revtex-subequations`：子公式組，各條 `$$...$$` 自動編號成 (1a)(1b)(1c)。
- `revtex-turnpage`：整頁旋轉 90 度橫置一個表格或圖（官方限制：一個區塊只能放一個）。
- `revtex-longtable`：跨頁長表格，每頁自動重複表頭。
- `revtex-appendix`：其後的章視為附錄，編號自動改為 A、B、C。
- `revtex-bibliography`：參考文獻清單，支援三種寫法——`[1] 作者…` 逐條編號、`1. 作者…`、或乾脆不寫編號讓它照順序自動編；也可以改用 `.bib` 走完整 BibTeX 流程。舊版具名鍵寫法（`key: 作者…`）仍完全相容，可與新寫法混用。

**內文引用**：用 `[[1]]`、`[[1, 3]]`、`[[2-14]]`（自動展開成逐一的鍵，PDF 上會印成 `[2–14]`），跟校內學位論文模式同一套慣例，不必再記 `[@key]` 這種舊語法（舊語法仍相容）。引用到書目裡沒有的編號時，編譯訊息會直接列出是哪幾個。

一般 Markdown 語法照常使用：章節、清單、表格、圖片、行內與區塊公式、交叉引用（`\ref`／`\eqref` 搭配 `{#id}`）、腳註 `[^id]`、跨欄圖 `![說明](path){#id wide}`、表格儲存格合併（該格內容只寫一個 `>` 即合併進左邊儲存格）。公式寬度與表格寬度由程式在編譯期實測，過寬時自動改用跨欄或縮放，不需要手動指定。

**圖片縮放會同步到 REVTeX。** 在左側點圖片後選 25／33／50／66／100% 或自訂百分比，Markdown 原始文字會保存為 `<img style="zoom:N%;">`；REVTeX 輸出會把一般圖的 100% 視為 `\columnwidth`，把 `title="*"` 的跨欄圖視為 `\textwidth`，再依百分比設定 `\includegraphics` 寬度。`style="width:N%;"` 與 `width="N%"` 也相容。這個圖片比例會影響輸出；底部閱讀倍率與 A4／臺灣論文表格單頁適配不會影響 REVTeX。

### 14.3 論文語法工具列

不想記這些圍欄語法，可以用工具列。左半 Markdown 編輯區上方的格式工具列最右側有 **REV**／**論文** 兩個分類鈕，點開會列出對應的小工具（前置、摘要、書目、引用、公式、跨欄等）。填完表單按「插入」，即可在游標位置加入完整語法區塊。臺灣論文工具的用法見第 13 節。

### 14.4 預覽與交付

- **右側「下載 PDF」**：下載目前由 TeX 編譯的 PDF；這是投稿前應逐頁檢查的版本。
- **右側「下載 .tex」**：下載使用目前學會、期刊與 class options 的 `main.tex`。
- **檔案 → 匯出 REVTeX 專案 (.zip)…**：正式交付建議用這個。內含 `main.tex`、文獻、原始 Markdown、圖片、編譯腳本、設定快照與 manifest；可攜版另附未改動的官方 REVTeX runtime。

REVTeX 文件請使用右側的 TeX PDF，不要改用一般向量 PDF、分批 PDF 或相容點陣 PDF。

**期刊最終的斷行與浮動體位置以 TeX 編譯出來的 PDF 為準。** 送出前請把右側 PDF 逐頁看過。

### 14.5 已知的官方限制（不是本程式的問題）

- `preprint` 會在摘要正前方加入官方可選軟分頁；短稿可能讓摘要留在首頁，當後續正文使文件變長時，TeX 可能改從第二頁開始。這不是固定的獨立標題頁。需要與官方手寫 LaTeX 完全一致時，將「首頁前置區分頁」保留為「依官方行為」；要避免作者與機構資訊之後留下大面積空白時，選「強制連續首頁（抑制摘要前軟分頁）」。
- `reprint` 的官方預設是 10 pt；明確加上 11 pt／12 pt 不是單純放大文字，而是改用另一套版面 grid。在 AIP／RSI、Letter、雙欄長稿中，官方 class 本身可能因此把第一頁正文排到距紙張下緣約 10 pt。這是合法但不適合作為一般 reprint 預覽的衝突組合；使用 `auto` 可回到官方 reprint 10 pt 幾何。
- 章節標題內不能放腳註（REVTeX 在移動參數中停用），程式已自動移除並提示改用作者標記欄位。
- 橫置表格的溢出警告是假警報（旋轉內容以未旋轉座標量測）。
- `a5paper` 等紙張官方只設定紙張寬度、不連動版心寬度，因此設定面板只暴露 letter 與 a4。
- Letters 類期刊（PRL、CP 等）本來就不編章節號。
- **跨欄區塊上下那兩條短線是官方設計。** 雙欄版面下，`widetext`（也就是 `revtex-wide` 圍欄）會在區塊上方靠左、下方靠右各畫一條約一欄寬的細線，線的一端還有一個小直角。它們是**接續記號**：上面那條標出左欄文字在哪裡中斷，下面那條標出右欄文字從哪裡接續，告訴讀者雙欄流程在此被跨欄內容打斷。官方 `revtex4-2.cls` 明確這樣定義，純官方寫法編出來也一樣，不是本程式畫的，也不應該移除。

# 第三部 · 設定與參考

## 15. 偏好設定逐項

「Ekdeta → 偏好設定…」（⌘,）分為**全局設定**、**論文輸出設定**與**國際論文模板**三個主分頁；所有變更即時生效並自動保存，也會包含在完整備份與資料夾同步中。

### 15.1 全局設定

- **介面與顯示**：介面語言（繁體中文／英文）、文件顯示倍率（50%–200%，只改螢幕顯示，不改 A4 幾何、頁數或 PDF）、格式工具列（可自訂顯示項目與順序，復原／重做固定在最左）、焦點模式、打字機模式。
- **圖片貼上與拖放**：先顯示「專案儲存資料夾（相對路徑基準）」，這是你明確授權的同步根目錄。三種存放方式：(1) 專案資料夾內的子資料夾（預設 `image`，可用 `assets/images` 等巢狀路徑）；(2) 另外指定圖片資料夾（實體資料夾與 Markdown 連結前綴分開設定）；(3) 一律 base64 內嵌。找不到可寫入位置時依序遞補。基於瀏覽器安全性，網頁無法顯示完整的作業系統絕對路徑。
- **字體與語系分配**：九個字體槽。一般 Markdown、臺灣論文中文正文、臺灣論文英文正文與舊版 Paper 文件都可分開指定中文字體與英文字體；程式碼／原始碼模式另有等寬字體。原始碼的輸入文字、語法著色與行號共用同一等寬字體，字元位置會保持對齊。Latin 槽控制英文字母、數字與西文標點，中文槽控制漢字與全形標點；即使中文字體含英文字形，也不會蓋掉另設的 Latin 字體。留空即使用系統後備中文字體。自訂字體同樣用於 PDF 輸出。

### 15.2 論文輸出設定

- **臺灣論文封面標誌**：可選內建兩種校徽或自訂圖片，60%–140% 縮放，中英文模板共用同一選擇。支援 JPG、PNG、WebP、GIF、SVG，大型點陣圖自動縮小並保留透明背景。
- **分頁與自動編號**：「自動章節與圖片編號」預設開啟，替章節、圖片與表格產生編號並同步大綱與 PDF，不改寫 Markdown；原稿已自行編號時再關閉。「填滿每一頁」預設開啟，說明見第 12 節。
- **縮排設定**：中文與 English 各自獨立，說明見第 13 節。
- 臺灣論文的電子版／紙本版**只從「模式」選單切換**，不在偏好設定重複出現。

### 15.3 國際論文模板

這一頁提供 REVTeX 常用選項，包括 society、journal、稿件模式、紙張、字級、欄數、單位排列與引用格式；完整的文件級選項請使用 REVTeX 左側「版面設定」，說明見第 14 節。設定隨目前 REVTeX 文件保存，不影響臺灣論文或一般 Markdown。

## 16. 主題、模式、字體、字級與語言

- 一般主題：GitHub、Night、羊皮紙、Blackout、Blackout Game。後兩者是純暗色主題（無日間版對應），右上角明暗按鈕在這兩個主題下維持原主題。
- 寫作模式：Markdown 模式、臺灣論文中英文各版型，以及國際期刊 REVTeX 4.2。請從「模式」選單切換；更換「主題」只改外觀，不改分頁或輸出方式。
- Blackout 中相鄰的引言行（包括只含 `>` 的空引用行）會共用一個橘色圓角框；Blackout Game 的紅色只作用於正文中明示的粗體，標題與介面仍是白色。
- 右上角明暗按鈕只改螢幕顯示；論文 PDF 仍輸出白紙黑字。
- 一般模式每次字級調整 1 px，臺灣論文模式每次 0.5 pt。
- 「Ekdeta → 語言」切換繁體中文與 English，會依內建身分重新載入內建文件（歡迎與手冊切換語言，開發筆記維持中文技術內容，模板各自維持對應內容）。一般文件完全不動。
- **頁面縮放**：滑鼠移到文件區，按住 Command（Windows／Linux 為 Ctrl）並滾動滾輪。只改閱讀倍率，不改行寬、頁數或 PDF；狀態列倍率可點擊還原 100%。

## 17. 備份、還原與故障排除

遇到問題時依序處理：

1. **先匯出目前 `.md` 或完整備份**，不要先恢復原廠。
2. 重新整理頁面，確認是否只是未完成的編輯狀態。
3. 圖片失效時使用底部修復列或「選擇圖片資料夾」。
4. 已連結資料夾但無法同步時重新授權；必要時先解除連結再重連。
5. 向量 PDF 少圖時先確認原畫面是否已載入；相容點陣 PDF 少圖時重新選擇圖片資料夾再匯出。
6. 論文版面異常時，先還原字級與自訂字體，再確認使用的模式與電子／紙本變體。
7. REVTeX 編譯失敗時，右側面板會顯示錯誤訊息與行號；先看第一個錯誤，後面的多半是連鎖反應。
8. 仍無法排除時，保留 HTML、備份 JSON、原始 Markdown 與問題畫面。

## 18. 快捷鍵速查與系統切換

開啟「Ekdeta → Markdown 與快捷鍵速查」。視窗右上角有 **macOS／Windows／Linux** 三個切換按鈕，預設依目前瀏覽器平台選擇。切換只改變速查表顯示，不會重新綁定程式。

- 上半部按格式、段落、編輯、檔案與檢視分組；有多組可用快捷鍵時會全部列出，某平台沒有安全快捷鍵時顯示「僅選單」。
- 下半部「情境操作」只在尋找列、快速開檔、大綱過濾、補全面板、表格儲存格、浮動框或原始碼模式中生效；左側是操作名稱，右側是按鍵。
- Windows／Linux 不需要自行把 ⌘ 換成 Ctrl，面板會依實際事件顯示。
- 瀏覽器或作業系統仍可能攔截 Ctrl/⌘+N、Ctrl/⌘+O 等保留鍵，面板會標示，請改用選單。

## 19. 常用快捷鍵

## 20. 已知限制

- 向量 PDF 依賴瀏覽器的列印／另存 PDF 能力，因此正式匯出會開啟系統列印視窗，不能像點陣備援一樣靜默下載。
- 編輯畫面以連續內容模擬紙張；某些紙本模式的螢幕奇偶偏移是視覺近似，兩種 PDF 路徑都會另按逐頁幾何建立頁框。
- 巢狀行內語法的游標到原始碼映射仍可能有一兩個字元誤差。
- 超長單一表格列、單一不可拆物件或極端長行需要人工檢查。
- 複雜多行 HTML、iframe、腳本與事件屬性不支援。
- 沒有外掛系統或 Vim 模式。
- REVTeX 模式需要載入編譯引擎；未載入時右側只能顯示上一次的結果。
- **正式送出前必須逐頁檢查最終 PDF**，特別確認封面、字型、圖片比例、表格續頁、頁碼與目錄頁碼。
