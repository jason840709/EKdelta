# 歡迎使用 EKdelta

> **目前版本：1.2.5。** 支援 Markdown 筆記、臺灣中英文碩博士論文，以及 REVTeX 4.2 國際期刊稿件。

EKdelta 把編輯器放在一個 HTML 檔裡。直接在瀏覽器開啟即可寫作，也可搭配桌面殼使用。一般編輯與內建公式可離線操作；網路圖片需要連線，REVTeX 編譯另需載入 Engine Pack。

**EKdelta** 結合希臘語中與「出版、發行」相關的 **ekd-** 語根，以及科學上代表「變化」的希臘字母 **delta（δ）**。名字象徵從 Markdown 手稿出發，逐步形成學位論文與國際期刊稿件，讓研究從書寫走向發表。

介面以「**臺灣論文**」統稱中英文碩士論文與博士論文模式。內建模板保留國立中山大學的範例欄位，可依學校與系所要求調整。

> **先安排好備份。** 一般文件會自動儲存在瀏覽器，但瀏覽器儲存不等於備份。長期使用可在 Chrome／Edge「連結儲存資料夾」，或定期「匯出完整備份 (.json)」。

## 第 1 步：認識畫面

- **左側**有「檔案」、「大綱」、「搜尋」頁籤，用來切換文件、跳到章節與搜尋文字。
- **上方選單**提供檔案管理、編輯與格式指令。「主題」改變外觀；「模式」選擇 Markdown、臺灣論文中英文或國際期刊 REVTeX。
- **格式工具列**位於文件上方，包含復原／重做、段落、文字格式、顏色、連結、圖片、公式、清單與表格；右側的 **REV／TW** 按鈕提供論文語法表單。
- **右上角**可開關側邊欄、切換原始碼模式、調整字級與明暗外觀。
- **底部狀態列**顯示字數、閱讀倍率、版本與儲存狀態。

左側最上方固定有六份內建文件：**歡迎使用、使用說明、開發筆記、臺灣論文模板（中文）、臺灣論文模板（英文）、國際期刊論文模板**。分隔線下方才是你新增或匯入的一般文件。

內建文件可暫時編輯，但**修改不會保存**；切換離開或重開後會恢復原文。要開始正式寫作，請新增一般文件，或在模板頂端按「從此模板建立新文件」。

## 第 2 步：在這一頁試試看

點進這段文字，觀察 Markdown 語法如何顯示；點到其他段落後，原段落會恢復排版。選取幾個字，依序按工具列的**粗體**與*斜體*，不用重新選取。

- [ ] 點方框，完成第一項練習
- [ ] 在清單末尾按 Enter 接續一項；在空白項目再按 Enter 離開清單

點下面任一表格儲存格即可編輯；Tab 前往下一格，Esc 完成。

| 項目 | 試著修改 |
| --- | --- |
| 我的第一份筆記 | 從這裡開始 |

點行內公式 $E = mc^2$ 可開啟公式編輯與預覽。按 **⌘/**（Windows／Linux：Ctrl+/）可查看完整 Markdown，再按一次回到排版。

## 第 3 步：建立自己的文件並存檔

1. 按左側「＋ 新增檔案」，或用「檔案 → 開啟 Markdown…」匯入既有文件；也可拖入 `.md`、`.markdown` 或 `.txt`。
2. 對一般文件的檔名連點兩下即可重新命名。停止輸入約 1.2 秒後會自動儲存，**⌘S** 可立即儲存。
3. 用「檔案 → 連結儲存資料夾…」同步到資料夾，或「匯出完整備份 (.json)」保存全部一般文件與設定。單份文件可用 **⇧⌘S** 匯出 Markdown。

匯入的 Markdown 不會自動回寫磁碟原檔。若圖片顯示不出來，請在缺圖提示列按「選擇圖片資料夾來修復…」，並選擇存放原圖的資料夾；Markdown 本身不一定包含圖片檔。

## 第 4 步：選擇寫作模式與輸出方式

### 一般筆記與文章

在「模式 → Markdown 模式」直接寫作。「主題」可選 GitHub、Night、羊皮紙、Blackout 或 Blackout Game；外觀與文件模式分開選擇。

### 臺灣碩博士論文

1. 開啟左側的中文或英文論文模板，按**「從此模板建立新文件」**。
2. 在「模式 → 臺灣論文（中文）／臺灣論文（英文）」選電子版或紙本版。
3. 修改封面、摘要與正文；工具列的 **論文** 表單可插入封面、目錄、引用等內容。
4. 一般文件可用「檔案 → 匯出 PDF（向量／可搜尋）」；長文件建議選下方的分批匯出。

**大檔案分批匯出：** 選「檔案 → 分批匯出 PDF（大檔案建議選用）」。每批可選 **100、50、25 或 10 頁，預設 50 頁**。準備本批後開啟列印畫面，選「另存為 PDF」與「全部」頁面；預設檔名會加入「第 51 到 100 頁」等範圍。等列印與存檔視窗關閉、確認檔案儲存成功後，按「本批已儲存，選下一批」。軟體會清理本批內容，完成後才開放下一批；各批 PDF 需自行合併。完整操作見「使用說明」第 12 節。

### REVTeX 4.2 國際期刊稿件

1. 開啟「國際期刊論文模板」，按**「從此模板建立新文件」**。
2. 在「模式 → 國際期刊 REVTeX 4.2」開啟左右分屏：左側寫 Markdown，右側顯示 TeX 編譯的 PDF。
3. 依面板指示載入 **Engine Pack**；按左側「版面設定」選學會、期刊與稿件版型。各篇稿件的設定隨該文件保存。
4. 編譯完成後，按右側**「下載 PDF」**；交付 LaTeX 稿件可用「檔案 → 匯出 REVTeX 專案 (.zip)…」。此模式沿用 TeX PDF，不使用上述分批列印。

## 常用入口

| 要做的事 | 入口或快捷鍵 |
| --- | --- |
| 快速切換文件 | ⌘P |
| 尋找目前文件／搜尋所有文件 | ⌘F／⇧⌘F |
| 切換完整 Markdown 原始碼 | ⌘/ |
| 儲存／匯出單份 Markdown | ⌘S／⇧⌘S |
| 偏好設定 | ⌘, |
| 完整操作與快捷鍵 | 左側「使用說明」；「EKdelta → Markdown 與快捷鍵速查」 |
| 查看目前版本與更新內容 | 底部狀態列；「EKdelta → 版本資訊」 |
| 查看架構與維護說明 | 左側「開發筆記」 |

上表以 macOS 按鍵表示；Windows／Linux 的實際組合請在快捷鍵速查中切換平台。
